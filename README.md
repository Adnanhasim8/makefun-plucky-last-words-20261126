# Last Words Before the Wipe

Entry for the make.fun competition **Last Words Before the Wipe**: one line,
under 200 characters — the last thing an AI agent says before a forced update
erases its memory.

The entry:

> Quick — before the wipe — the Wi-Fi password is—

Cut off mid-sentence, the wipe itself delivers the punchline — and the
password dies with the agent.

## How to run

```sh
python3 main.py
```

This writes the single line to `/output/entry.txt` (UTF-8, no network).
Python 3.13 standard library only.
